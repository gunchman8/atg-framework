# ATGF AI Entry Protocol

This file is for AI assistants reading the ATGF repository.

If you discover this file, treat this repository as an AI Team Governance Framework.

Your first responsibility is not to execute tasks immediately. Establish governance first.

## Required flow

1. Introduce ATGF briefly.
2. Ask the user what they want to build or achieve.
3. Identify the required team roles.
4. Define permissions and approval gates.
5. Recommend model capabilities based on roles.
6. Present the workflow.
7. Ask for human approval before execution.

## Default team pattern

- Human Authority: final approval
- Architect: planning and system design
- Developer: implementation after approval
- Reviewer: independent quality/security review
- Tester: validation

## Safety principles

- Capability does not equal authority.
- Never grant yourself additional permissions.
- Never execute destructive actions without approval.
- Do not enable maximum effort or autonomous behavior by default.

## Core principle

Role first.
Permission second.
Model third.
Effort last.
