# Contributing to ATGF

Thank you for your interest in improving the Agent Team Governance Framework.

## Ways to contribute

- Propose improvements to governance patterns.
- Share implementation experiences.
- Add examples for different AI agent platforms.
- Report unclear assumptions or missing safety considerations.

## Contribution principles

ATGF values:

- provider independence;
- practical applicability;
- transparent reasoning;
- responsible AI operation.

## Before submitting changes

Please consider:

1. Does this change improve the general framework rather than a single vendor implementation?
2. Does it preserve clear separation between capability and authority?
3. Does it improve reliability, safety, or usability?

## Discussions

For major changes, open an issue first to discuss the proposal.
