# ATGF Architecture

ATGF defines a governance layer above individual AI models and tools.

```
Human Authority
        |
Governance Layer
        |
+-------+--------+--------+
|       |        |        |
Planner Builder Reviewer
|       |        |
+-------+--------+
        |
Validation Layer
        |
Execution Layer
```

The framework is provider-independent and can be adapted to different AI agent platforms.
