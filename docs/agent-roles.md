# Agent Roles

## Planner Agent

Responsible for task decomposition, scope definition, and dependency analysis.

## Research Agent

Responsible for evidence gathering and uncertainty identification.

## Builder Agent

Responsible for implementation within approved boundaries.

## Reviewer Agent

Responsible for challenging assumptions, finding risks, and validating quality.

## Auditor Agent

Responsible for comparing expected and actual outcomes.

A reliable team separates responsibilities instead of creating one unrestricted super-agent.
