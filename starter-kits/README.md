# ATGF Starter Kits

## Không biết AI? Bắt đầu ở đây.

ATGF không yêu cầu bạn hiểu agent, model hay lập trình.

Hãy chọn đúng bộ khởi động:

## Beginner

Dành cho người mới sử dụng AI.

Bạn chỉ cần:

1. Mở AI assistant.
2. Dán prompt hướng dẫn.
3. Nói mục tiêu bạn muốn làm.
4. AI sẽ đề xuất đội hình và xin xác nhận trước khi hành động.

## Coding Team

Dành cho:

- Codex
- Claude Code
- Cursor
- các coding agent khác

Bộ này giúp AI tổ chức thành:

- Architect
- Developer
- Reviewer
- Tester

với role, permission và workflow rõ ràng.

## Nguyên tắc cốt lõi

Không bắt đầu bằng model mạnh nhất.

Bắt đầu bằng:

```
Role → Permission → Model → Effort
```

AI có năng lực không có nghĩa AI có toàn quyền.

ATGF giúp biến AI từ một công cụ đơn lẻ thành một đội ngũ có tổ chức.
