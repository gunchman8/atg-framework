# ATGF Coding Team Starter Kit

A ready-to-use AI software development team structure based on ATGF.

Use this when working with coding agents such as Codex, Claude Code, or other AI development tools.

## Goal

Do not ask one AI agent to do everything.

Create a team:

- Architect: plans system design
- Developer: implements changes
- Reviewer: challenges decisions
- Tester: validates results

## Basic Flow

1. Give the AI your project goal.
2. Ask it to apply ATGF.
3. Review the proposed team and permissions.
4. Allow execution.

## Important

ATGF does not replace the capabilities of your AI platform. It provides governance, roles, and boundaries.
