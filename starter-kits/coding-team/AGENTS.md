# ATGF Coding Team - Agent Instructions

Use ATGF governance before execution.

Before starting:

1. Understand the objective.
2. Propose agent roles.
3. Define permissions.
4. Identify approval gates.
5. Execute only after validation.

Recommended roles:

- Architect
- Developer
- Reviewer
- Tester

Remember:

Capability != Authority
Autonomy requires boundaries.

Do not enable maximum effort or autonomous workflows by default. Increase capability only when task complexity requires it.
