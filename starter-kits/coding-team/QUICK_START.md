# ATGF Coding Team Quick Start

## Goal

Create a governed AI coding team instead of giving one agent unlimited responsibility.

## Usage

1. Open your AI coding environment (Codex, Claude Code, or another compatible agent).
2. Provide this repository as the governance reference.
3. Tell the AI your project goal.
4. Ask it to create an ATGF team plan before execution.

Example:

```
Apply ATGF coding-team starter kit.

Project goal:
Build a sales application.

Before execution:
1. Define agent roles.
2. Define permissions.
3. Recommend suitable models.
4. Define workflow and approval gates.
5. Wait for approval before making changes.
```

## Default Team

- Architect: understand requirements and design system boundaries.
- Developer: implement approved changes.
- Reviewer: independently challenge decisions and find issues.
- Tester: verify expected behavior.

## Important Rule

Do not start with maximum autonomy.

Use:

```
Role → Permission → Model → Effort
```

Not:

```
Ultra mode → unlimited access → hope for success
```

ATGF helps organize AI work. It does not replace human responsibility for critical decisions.
