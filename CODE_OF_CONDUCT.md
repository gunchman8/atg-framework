# Code of Conduct

## Our commitment

ATGF aims to be an open and respectful community for discussing AI agent governance.

## Expected behavior

Contributors should:

- communicate respectfully;
- provide constructive feedback;
- distinguish evidence from assumptions;
- welcome different technical perspectives.

## Unacceptable behavior

Harassment, personal attacks, discrimination, or intentionally misleading contributions are not acceptable.

## Scope

This applies to all project interactions including issues, pull requests, and discussions.
